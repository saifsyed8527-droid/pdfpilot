# Blur Face — 30 October 2026

Adds the 105th public tool, preserving the existing file selection → preview/options → processing → automatic/repeat download flow. The nine protected Merge/Split flow files remain byte-for-byte unchanged.

## Shipped behavior

- Local face location suggestions for one image or a batch, three sensitivity levels, editable expanded coverage and overlapping tile scanning in More suggestions. Up to 20 images, 100MB each, 200MB combined, 20 megapixels each and 100 areas per image.
- Manual drawn/center areas, move/resize, keyboard movement, exact pixel coordinates, enable/disable/delete, undo/redo, original preview and zoom. No person identification or portrait matching.
- Soft blur, pixelation or opaque solid cover; rectangle/ellipse; PNG/JPG/WEBP and uniquely named batch ZIP outputs. Export refuses any image without an enabled area. Encoding removes original metadata; animation uses the first frame.
- Model/runtime are pinned, verified and served locally. Detection runs in a cancellable worker with same-origin-only network access and worker-scoped WASM permission. Page security policy is unchanged. Model download is approximately 10MB for the selected SIMD or non-SIMD runtime, on first use.

## Fixes found during validation

The initially considered full-range model had an incompatible anchor count; it was removed and replaced with the compatible short-range model. More-suggestions tile scans now use a confidence floor and containment deduplication to reduce false positives. Decimal normalization could expand integer mask boundaries by one pixel; bounded epsilon handling plus an output-pixel regression test fixes this. A stale hot-reload browser was refreshed and the corrected output re-downloaded and rechecked.

## Limits

Detection may miss small, turned or obscured faces and users must inspect every image. Blur/pixelation reduce detail but do not guarantee anonymity; solid cover replaces the selected pixels. This is face location detection, not identity recognition. WEBP/JPG may change pixels outside selected areas through lossy encoding; exact exterior preservation was verified for PNG. Tests use public/synthetic fixtures, not private user portraits. No Safari/mobile hardware certification is claimed by a responsive viewport test.

Only the configuration evidence hashes and previously matching capability fingerprints were refreshed for the new worker header. Existing PDF-to-Word/OCR/Scan behavior, review content and status were not changed.
