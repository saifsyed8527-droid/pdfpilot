# Sign PDF and signature placement — 29 October 2026

The new Sign PDF route uses the existing editor's page preview, selection, styling, history, processing and download flow. It adds shortcuts for signatures, initials, image stamps, names and dates. The original Merge/Split reference files are unchanged.

## Changes checked

- Drawn signatures retain separate pen strokes instead of joining the end of one stroke to the next. Resizing now scales the ink in both preview and PDF export. Signature coordinates account for the canvas's displayed size.
- Typed signatures support regular, italic and bold styles and three ink colors. PNG/JPEG uploads preserve aspect ratio and transparency, validate the image, and reject oversized or invalid inputs. A failed replacement clears the previous image instead of inserting it accidentally.
- Remembering a signature is opt-in. Stored values are validated before reuse. The modal traps keyboard focus, closes with Escape, returns focus to its trigger and fits a narrow viewport.
- Source PDFs are copied into a stable in-memory File once, so a subsequent change to the original disk file cannot invalidate export. Results return to the top of the page.

## Output verification

- Two focused regression tests verify separate strokes, resized ink and untouched gaps in decoded PDF pixels on four cropped pages with native rotations 0, 90, 180 and 270 degrees, plus coordinate conversion and saved-signature validation.
- Browser download `signed.pdf` contains four pages: italic `QA Signature`, bold blue `QA` rotated 25 degrees, a transparent PNG stamp rotated 15 degrees, and `Test User` with `2026-10-29`. Independently opened with pypdf and rendered with PDFium: page rotations, extracted text, image presence and visible placement were checked.
- Replacing a valid stamp with a malformed PNG disabled insertion and showed an error; selecting a valid image again recovered successfully.
- At 390 × 844 the document has no horizontal overflow and the signature dialog is fully within the viewport. Tab wraps from Insert to Close; Escape closes the dialog and restores focus to Signature.
- Full regression suite: 281 passed, zero failures. Type checking and production build passed; lint reported the same three pre-existing warnings. All nine protected Merge/Split reference-file hashes match the baseline.
- Production verification on 30 October: `/sign-pdf` generated `signed (1).pdf` with bold blue `QA` initials at 25 degrees on the second, natively rotated page. The four-page download reopened with pypdf and rendered with PDFium. PR #14 and Vercel production deployment completed successfully.

## Scope

These are visual signatures placed by the document's current user. Certificate-based signing, identity verification, recipient invitations, reminders and audit trails are not provided. SVG signature upload is not supported. No contract was signed or sent during verification; all documents and signatures were synthetic test fixtures.

The focused output tests cover the draw/export geometry; automated browser input did not simulate a full pen gesture. Existing editor text/OCR limitations continue to apply. These checks do not establish zero defects or complete competitor parity.
