# sRGB v2 color profile

`srgb-v2.icc` is generated by Little CMS 2's `cmsCreate_sRGBProfile`, with `cmsSetProfileVersion(profile, 2.1)` before serialization. It describes the standard sRGB primaries, D65 white point, chromatic adaptation and transfer curves. It contains no device-specific measurements or third-party branding. PDFPilot embeds it as the output intent for opaque RGB archive pages.

The generating library is Little CMS 2 (MIT license): https://github.com/mm2/Little-CMS
